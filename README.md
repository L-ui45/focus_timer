# 番茄专注钟

一个零依赖的番茄专注钟：页面正中央显示 `25:00`，下方提供「开始 / 重置 / 停止」三个按钮。

## 文件结构

```
focus_timer/
├── index.html   # 页面结构（引用 style.css 与 script.js）
├── style.css    # 居中布局与按钮样式
├── script.js    # 25 分钟倒计时逻辑
└── README.md    # 项目说明
```

## 运行方式

直接用浏览器打开 `index.html` 即可，无需安装依赖或启动服务。

## 按钮行为

| 按钮 | 行为 |
| --- | --- |
| 开始 | 从当前剩余时间开始倒计时；运行中不可重复启动（按钮置灰） |
| 停止 | 暂停倒计时，保留剩余时间，可再次点「开始」继续 |
| 重置 | 停止倒计时并恢复到 `25:00` |

倒计时到 `00:00` 后自动停止，「开始」按钮置灰；点击「重置」可重新开始一轮。
